# PHI Data Quality Rules

PHI academic data should follow these rules.

## Verified Data
Data obtained from an authoritative academic source may be stored as verified.

## Unverified Data
Information that has not been confirmed should not be presented as official.

## Missing Data
Missing fields should remain null, unknown, or explicitly unavailable.

## Derived Data
Calculated values should identify their source fields and derivation logic.

## Conflicting Data
When two sources disagree, the conflict should be preserved until resolved.

## Historical Data
Historical academic records should not be overwritten merely because newer
semester information becomes available.

## Auditability
Important changes to academic records should remain traceable to their source
or processing step.
