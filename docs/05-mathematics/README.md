# 05 · Mathematics

**Status:** Draft
**Last Updated:** 2026-08-02

## Purpose

Document mathematical models, formulas, and derivations underpinning any quantitative or ML components of Project PHI.

## Scope

Covers formal math content: notation, derivations, proofs, and model equations. Does not cover implementation code, which lives in models/ or 06-ai.

## What Belongs Here

- Formula references and derivations
- Notation glossaries
- Statistical/ML theory notes relevant to the project

## Naming Convention

Use kebab-case markdown files, e.g. `loss-function-derivation.md`.

## Example Files

- `notation.md`
- `loss-function-derivation.md`

## Best Practices

- Show derivation steps, not just final formulas
- Keep notation consistent across documents; define it once and link to it
- Link math docs to the model code that implements them
