**Status:** Draft
**Last Updated:** 2026-08-02

## Purpose

Serve as the single entry point and index for the entire AI Operating System (AIOS) documentation set — the first place any human or AI agent should look to understand how this project's documentation is organized and where to go next.

## Scope

Covers cross-cutting navigation, system-wide status, and links into every other docs/ section. Does not contain deep technical content itself — that lives in the numbered sections it points to.

## What Belongs Here

- Master index / table of contents for docs/
- Current system status summaries
- Links to active playbooks, roadmap, and decisions
- Onboarding entry point for new contributors (human or AI)

## Naming Convention

Use kebab-case markdown files, e.g. `system-status.md`, `index.md`.

## Example Files

- `index.md`
- `system-status.md`
- `agent-directory.md`

## Best Practices

- Keep this folder lightweight; it should link out, not duplicate content
- Update the index whenever a new docs/ subfolder or major doc is added
- Review quarterly for stale links
