# PHI Research Hypotheses

## Primary Hypothesis

Golden Ratio and Fibonacci-derived features may contain statistically useful
out-of-sample information about market behavior.

## Null Hypothesis

After realistic controls, transaction costs, walk-forward validation, and
multiple-testing safeguards, Golden Ratio/Fibonacci features provide no
reliable predictive advantage over appropriate baselines.

## Research Principle

PHI must be capable of falsifying its own hypothesis. A profitable backtest
alone is not sufficient evidence.

## Required Comparisons

> **Superseded (lay summary).** This five-item list is a plain-language summary. The **canonical** comparison framework is the six-category control set in PRD [§18](../02-project/PHI_PRD.md#18-control--placebo-framework) (PRD-CONTROL-001…006), frozen for the first φ feature in [ADR 0002](../18-decisions/0002-phase2-feature-and-control-design-lock.md) and the [feature & control contract](../05-mathematics/phi-retracement-feature-contract.md). Use those; the list below is retained only for orientation.

Every material result should be evaluated against:

- Naive baseline
- Conventional market features
- Randomized/placebo features
- Appropriate benchmark strategy
- Golden Ratio/Fibonacci features

## Evidence Standard

A result is considered credible only when it survives out-of-sample evaluation
and the documented validation protocol.
