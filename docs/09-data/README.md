## Purpose

Document data pipelines, schemas, and data dictionaries used across Project PHI.

- Pipeline overviews

## Example Files

- `data-dictionary.md`
- `pipeline-overview.md`

- Note data sensitivity/PII classification explicitly
- Link to 12-security for handling requirements
