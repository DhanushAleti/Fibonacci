# 01 · AI Playbooks

**Status:** Draft
**Last Updated:** 2026-08-02

## Purpose

Define role-specific operating instructions for each AI model/agent involved in building and maintaining Project PHI (e.g. Claude as engineer, ChatGPT as architect, Gemini as analyst, Perplexity for research).

## Scope

Covers behavioral contracts, responsibilities, and hand-off protocols between AI roles. Does not cover product requirements or architecture decisions themselves.

## What Belongs Here

- Per-model/per-role playbooks
- Cross-agent collaboration protocols
- Task-specific playbooks (code review, debugging, feature planning)

## Naming Convention

Use `snake_case.md` matching the role or task name, e.g. `claude_engineer.md`.

## Example Files

- `PHI_SYSTEM.md`
- `claude_engineer.md`
- `chatgpt_architect.md`

## Best Practices

- Keep each playbook focused on one role or one task
- Version playbooks when responsibilities change materially
- Cross-link related playbooks instead of duplicating instructions
