## Purpose

Document API contracts, endpoints, and integration specifications for Project PHI.

## Scope

Covers API-level documentation such as endpoint references and contracts. Does not cover backend implementation detail, which lives in 07-backend.

## What Belongs Here

- Endpoint references
- Request/response contracts
- Versioning and deprecation notes

## Naming Convention

Use kebab-case markdown files, e.g. `endpoints-v1.md`.

## Example Files

- `endpoints-v1.md`
- `auth.md`

## Best Practices

- Keep contract docs in sync with the actual API implementation
- Use the API_TEMPLATE.md in 15-templates for new endpoint docs
- Call out breaking changes and deprecations clearly
