**Status:** Draft
**Last Updated:** 2026-08-02

## Purpose

Capture the project-level context for Project PHI: vision, goals, stakeholders, and high-level scope.

## Scope

Covers what the project is and why it exists. Does not cover implementation detail, which lives in 03-architecture onward.

## What Belongs Here

- Project charter / vision docs
- Stakeholder and ownership maps
- Goals and success metrics
- High-level scope and non-goals

## Naming Convention

Use kebab-case markdown files, e.g. `project-charter.md`, `stakeholders.md`.

## Example Files

- `project-charter.md`
- `vision.md`
- `stakeholders.md`

## Best Practices

- Keep this section stable; changes here should be intentional and reviewed
- Reflect real decisions, not aspirational ones
- Link out to 18-decisions for anything that changes project direction
