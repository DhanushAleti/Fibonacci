# 14 · Prompts

**Status:** Draft
**Last Updated:** 2026-08-02

## Purpose

Maintain the prompt library and prompt engineering notes used across AI workflows in Project PHI.

## Scope

Covers reusable prompt content and prompting notes. Model/role behavior contracts live in 01-ai-playbooks.

## What Belongs Here

- Reusable prompt templates
- Prompt versioning and iteration notes
- Prompt evaluation notes

## Naming Convention

Use kebab-case markdown files, e.g. `code-review-prompt.md`.

## Example Files

- `code-review-prompt.md`
- `debugging-prompt.md`

## Best Practices

- Version prompts when their behavior changes materially
- Note which model(s) a prompt was validated against
- Link prompts to the playbook that uses them
