# 21 · Releases

**Status:** Draft
**Last Updated:** 2026-08-02

## Purpose

Document release notes and changelogs for Project PHI.

## Scope

Covers what shipped and when. Does not cover the process of releasing, which lives in 16-workflows/RELEASE_WORKFLOW.md.

## What Belongs Here

- Release notes
- Changelogs
- Version history

## Naming Convention

Use a version prefix, e.g. `v0.1.0.md`, or a rolling `CHANGELOG.md`.

## Example Files

- `CHANGELOG.md`
- `v0.1.0.md`

## Best Practices

- Use the RELEASE_TEMPLATE.md in 15-templates for each release
- Keep entries in reverse-chronological order
- Call out breaking changes prominently at the top of each entry
